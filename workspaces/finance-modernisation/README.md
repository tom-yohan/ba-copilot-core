# Project Workspace Template

Use this folder as a starting point for a project or client-specific workspace.

## Structure

    notes/       - Sanitised working notes
    outputs/     - Generated and reviewed outputs
    knowledge/   - Curated supporting knowledge
    decisions/   - Decision logs and key choices
    prompts/     - Project-specific prompt variations

## Safety

Do not commit confidential, regulated, client-owned, employer-owned, or personal data unless explicitly approved.

## Recommended Workflow

1. Add sanitised notes to `notes/`.
2. Run analysis using Open WebUI or CLI tooling.
3. Save reviewed outputs to `outputs/`.
4. Capture key decisions in `decisions/`.
5. Move reusable patterns back into the core repo.
